# SIBURI

An application for identifying significant bacteriuria with the help of color analysis.

## Steps to Run the Application

1. **Download and Extract:** Download the entire project and extract it into a directory.
2. **Install Node.js:** Download and install [Node.js](https://nodejs.org/en/download).
3. **Navigate to Directory:** Open Windows Command Prompt (in **Administrator mode**) or your Linux/macOS Terminal and navigate to the extracted project directory.
4. **Run Commands:** Execute the following commands in order:
   ```bash
   npm install next react react-dom
   npm run build
   npm start
5. **Open in Browser:** Open the provided link (e.g., http://localhost:3000/) in your web browser.
