# SIBURI
An application for identifying Significant bacteriuria with the help of color analysis.

## Steps to run the application
1) Download the entire project and extract it in a directory.
2) Install `Node.js` from the webpage: `https://nodejs.org/en/download`.
3) Use Windows CMD (Administrator mode) or Linux Terminal to locate to the extracted project directory.
4) Type the following commands:
   a) `npm install next react react-dom`
   b) `npm run build`
   c) `npm start`
5) Open the link `http://localhost:3000/` in a web browser.
